# VS. Balls

## Overview
A browser-based ball combat game where players spawn different types of balls with unique abilities that fight each other in an arena. Built as a single-page HTML application with canvas rendering and Tailwind CSS for UI.

## Project Architecture
- **Single file**: `index.html` contains all HTML, CSS, and JavaScript
- **No build system**: Pure client-side application, no bundling or compilation
- **Static hosting**: Served via `npx serve` on port 5000
- **Dependencies**: Tailwind CSS loaded via CDN

## Running
The app is served as a static site using the `serve` npm package on port 5000.

## Deployment
Configured as a static deployment serving the root directory.
